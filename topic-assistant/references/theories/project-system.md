# 项目制

模块：财政与资源。本卡“verified”仅表示下述基础命题与所列实际读取内容相符，不表示原著全文已读或本轮选题得到验证。

## 核对依据

[周雪光（2015）《项目制：一个“控制权”理论视角》](https://web.stanford.edu/~xgzhou/zhou_15_project.pdf)。读取范围：作者原论文 PDF，题名、摘要与控制权分析。

## 基础命题

专项项目的资源配置与控制权安排可改变政府间关系及基层行动。

## 概念与分析层级

分析单位：一个项目周期及政府间资源关系。核心概念：专项资金、申报、验收、控制权。层级以该单位为准，不能把个体自述直接推成组织或地区效应。

## 研究设计建议

以下为本库的应用建议，须用本次材料检验，不是原文已证实的中国案例结论。

- 适用与中国情境：聚焦一种项目的申报、配套、验收或维护环节；区分渠敬东、周飞舟等不同研究视角。
- 待检验机制：专项规则与资源竞争→申报和执行取舍→持续供给。
- 可观察材料与方法：项目通知、预算决算、验收材料、运维记录；追踪项目周期，必要时对照非项目供给。
- 决策落点：判断某项资金规则或验收条件是否应调整，兼顾后续维护成本。
- 边界与竞争解释：不是所有政府项目都构成项目制解释；与财政约束、采购能力和需求变动竞争。
