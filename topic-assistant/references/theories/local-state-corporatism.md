# 地方国家公司主义

模块：财政与资源。本卡“verified”仅表示下述基础命题与所列实际读取内容相符，不表示原著全文已读或本轮选题得到验证。

## 核对依据

[Jean C. Oi（1995）The Role of the Local State in China's Transitional Economy](https://www.cambridge.org/core/journals/china-quarterly/article/abs/role-of-the-local-state-in-chinas-transitional-economy/EAC386CB45017EC3DE682B0A6D7770E8)。读取范围：原刊摘要/引入部分；线上回溯日期不作原发表年。

## 基础命题

用地方政府与地方经济组织的紧密利益和组织联系解释特定转型时期发展方式。

## 概念与分析层级

分析单位：特定历史时期地方政府与经济组织。核心概念：收益联系、组织协调、政企关系。层级以该单位为准，不能把个体自述直接推成组织或地区效应。

## 研究设计建议

以下为本库的应用建议，须用本次材料检验，不是原文已证实的中国案例结论。

- 适用与中国情境：迁移到当代前须核实产权、财政和政企关系已如何变化。
- 待检验机制：组织性收益联系→政府协调和资源支持→产业或公共任务表现。
- 可观察材料与方法：政企权责、财政收益、资源配置与地方发展史；历史比较并注明时代边界。
- 决策落点：确定应分离、透明化或协调的具体政企接口，检验公共目标是否受损。
- 边界与竞争解释：不能把任意招商活动都叫公司主义；竞争解释为市场机会、产业基础与规范监管。
