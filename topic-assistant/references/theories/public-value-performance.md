# 公共价值基础的政府绩效治理

模块：价值、绩效与责任。本卡“verified”仅表示下述基础命题与所列实际读取内容相符，不表示原著全文已读或本轮选题得到验证。

## 核对依据

[包国宪、王学军（2012）《以公共价值为基础的政府绩效治理——源起、架构与研究问题》](https://gggl.cbpt.cnki.net/portal/journal/portal/client/paper/d79d1af464dd99db301857f3c4202b18)。读取范围：原刊摘要。

## 基础命题

把绩效的价值建构、组织管理与协同领导联系起来，强调政府绩效的公共价值基础。

## 概念与分析层级

分析单位：一项政府绩效治理过程。核心概念：价值建构、组织管理、协同领导。层级以该单位为准，不能把个体自述直接推成组织或地区效应。

## 研究设计建议

以下为本库的应用建议，须用本次材料检验，不是原文已证实的中国案例结论。

- 适用与中国情境：针对某地一项绩效考核，说明谁界定绩效、谁承担成本、谁实际受益。
- 待检验机制：价值建构与管理安排→指标及组织行动→社会需求回应。
- 可观察材料与方法：指标形成过程、评价主体、业务产出与受益分布；不能只复算综合得分。
- 决策落点：重设一个确实偏离需求的指标或评价环节，并检验改动后的后果。
- 边界与竞争解释：不把理论命题当本次实证结论；与一般战略三角有联系但不是同一模型，通常无需双主理论。
