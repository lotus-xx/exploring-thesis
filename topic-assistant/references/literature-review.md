# 按用户 PDF 编写论文文献综述

用于最终报告中的逐题综述、论文综述章节和独立综述文章。用户要求综述可以直接复制到论文，因此选题报告中的综述也按论文正文写，不能以选题阶段为由默认降成说明卡。本文件落实课件原有写法，不另创固定栏目或统一字数。页码均为 PDF 物理页序。

多学科与纯论文：综述照常分析作者实际提出的理论、概念、证明、设计或方法；本地没有对应知识卡不妨碍理解引用。知识卡/外部查新不能冒充本轮论文。断网不自动降低已完成综述，按实际来源、阅读与书目是否充分判定。

## 来源与适用结构

原文件曾位于用户提供的“规范”目录；已安装 skill 只保存以下可执行提要，不要求每次重新读取四份 PDF。只有原文件也位于用户本次指定论文文件夹内时才可回核相应原页；否则不得读取原目录、相邻目录或其他历史位置。

| 来源 | 原页要求及本 skill 的应用 |
| --- | --- |
| 《论文选题的形成》T36 | 原页以叉号否定简单分成“国内相关文献研究、国外相关文献研究”，以勾号推荐 A/B/C 主题相关研究；每段围绕一个主题或问题，不罗列、不堆积，写研究现状而非发展现状，必须有述评及对自己研究的启示。默认遵循主题组织，不按国别机械切成两半；确有目标模板要求时在其内部继续按问题比较。 |
| 《文献综述写作方法》R25—27、41—43 | 独立综述文章的原有组成：题目、真实作者署名、指示性摘要、3—5 个关键词、引言、主体、结语或展望、参考文献。引言简明说明目的、内容、历史与现状，必要时界定新概念；主体依问题性质设小标题，分析不同观点，比较理论或实验依据并评述；结尾归纳、评论、提出后续研究建议。短篇可不单列结语，但仍保留评述及启示。 |

论文中的综述章节沿用课件的“引入—按主题展开主体—评述与启示”，参考文献随正文附全；它属于论文内部，不能为每个章节另加作者署名、摘要和关键词。只有交付独立综述文章才完整采用 R25—27 的前后结构，真实作者信息未知时在交付说明中指出，不编造署名。论文题目和综述主题可以相连，但“论文研究问题—数据方法—资源风险”是选题报告的说明内容，不能冒充综述写作格式。

## 正文怎么写

1. 从已保留题的实际问题确定范围和主题提纲。主体小标题直接指向文献中的研究内容、概念、解释或争论；数量随证据和问题确定，不机械规定三节，也不把所有主题挤成一个长段。引入可在综述标题下直接成段，不强加名为“引言”的小标题。
2. 只在用户指定论文文件夹的材料中选择综述来源。优先纳入与问题直接相关、具有代表性、能反映当前研究进展的一次文献，并兼顾不同观点和必要反证；对奠基性问题确有作用的经典文献可以保留。目录内缺少新近、代表性或原始材料时，如实缩小综述结论并标为待补证，不联网补写，也不读取其他目录填空。
3. 每段围绕一个具体问题，把有关研究联系起来写清发展脉络、代表性观点及异同；在适用处比较理论预设、概念/测量、材料、方法和发现，解释何处可比、何处不可比。不是每段都必须含这些项目，也不强迫每段引用多篇。不同意见与反证应得到恰当呈现。
4. 述评落实到实际依据及其能解释和不能解释的问题。结尾归纳已有认识、尚待解决的问题及其对拟研究的启示，可依内容使用“研究述评”等标题，或短篇并入收束段。不得泛称“研究不足”“有待深入”，不得仅因未读到就断言前人未研究。
5. 综述是连贯的学术正文。不能以“研究问题：”“已有研究做到哪一步：”“本题要增加的认识：”“资料与方法：”“条件与风险：”等字段串联代替；这些说明可以留在报告其他部分。辅助表格可服务比较，但不能代替主体论述。
6. 综述独立可读：不用“供你参考”“建议你选”“本批材料”“见上题”“以后再补”等对话或流程用语，不泄漏 P001/E001 等内部编号、文件路径、检索日志、评分或待填占位。实际限定范围和必要的学术不确定性必须保留；若写正式的限定语料综述，可以如实交代其材料范围和方法，不能为消除流程腔而伪装成全面领域综述。
7. 每个保留题附该综述实际引用的完整书目，从同一来源台账派生。先使用用户指定的院校、期刊或论文模板体例；没有目标体例时，选择一个当前适用的国家标准引用体系并贯穿全文，同时在 `reference_style_basis` 记录所选体例、版本和选择依据。课件只要求采用明确且一致的体例，不能声称课件强制采用作者—年份制，也不能只替换文内标记就宣称格式合格。顺序编码须按本文件首次引用连续编号；若逐题材料需要独立重新编号，应作为独立文档登记，不能在同一报告让一个编号指向不同来源，也不能把带有全报告编号缺口的段落宣传为已适配用户论文的引文编号。

共享的是阅读证据、指定目录内核对结果和书目元数据；不让用户为了复制某题综述再拼接其他章节。先筛至最多五题，再仅写入选题。可直接复用相同且确实适用的已核表述，按题补足必要上下文与差异；不为“独立成文”重复查找或重新精读全部文献。

## 可直接使用的验收边界

在同一次内容审核中核对以下事项；在现有 manifest.report.review 的语义审核说明中记下所用 PDF 页序、核过的题目及实际缺口。最终交付前将逐题结果填入同一 language-review.json 的 literature 字段，字段见产物约定；不另建评分或多轮审校文件。

- 结构：按 T36 的主题方式组织，R25—27 的引入、主体比较及评述/展望功能齐全；主体小标题对应具体内容，层级连续。不得拿前述说明字段代替综述。
- 选材：在指定目录内核对代表性、一次文献优先、新近性和观点覆盖；经典材料保留有明确理由。材料不足时降低结论并标待补证，不扩大本地或联网证据范围。
- 内容：有归纳、比较和有依据的评价，能引出研究问题；研究现状与行业发展背景分清，既有结论与拟研究计划分清。对方法、结果和缺陷的评论均有相应已读原文支撑。
- 复制范围：每题综述正文完整、自洽，其后附本题引用书目；选题建议、资源风险、阅读限制说明及未核事项与正文分开。逐项确认没有未解决的主张或引文问题；影响结论的真实边界不能仅从正文挪走。
- 引用：主张与实际访问深度匹配，书目信息核全，正文与书目一一对应，所有引用条目实际读过相应内容。只见题录不进入正式论述；只见摘要不足以支持正文方法和局限的评价。需要全文才能成立的判断先定点补读；补不到就缩小论述或标明待补证。
- 格式：Markdown 使用连续的标题层级，不得跳级；参考文献标题与其所属层级一致。院校/期刊模板决定复制进论文后的字号、缩进与行距；课件未统一规定的数值不杜撰为规范。

通过上述核对且证据、书目完整，才可称“可复制使用的综述正文”。材料不足、条目待核、范围不匹配或关键判断未解决时，在正文外明确标为“待补证综述稿”并说明缺项；不得仅因格式齐全、达到字数或技术检查通过就称可直接使用，更不能保证免除导师/目标模板审阅。文献综述没有本包自定的 800—1,500 字门槛；篇幅以真实主题展开及用户/目标要求为准，不靠重复背景凑字数。

逐题综述状态只依据该综述实际使用的文献、论述及书目判断。未来研究的问答样本尚未采集、研究现场尚未进入或仅供设计使用的外部政策待核，应列入选题可行性；它们本身不使已合格的文献综述降级或重写。若这些缺口确实影响综述中的某项主张，应定位该主张后限缩，不能笼统要求整章重读。

内容核对完成后沿用一次全文语言审校和最终 Markdown 校验；保留课件要求的正常学术标题与述评，不因去 AI 味破坏综述结构。内容验收使用 final.md 最终版本行范围，分别定位正文和紧随其后的本题书目，内部编号不写入论文。脚本拦截未验收/漏题、书目缺项或混入无关条目、无已读证据、未核著录及把基础书目冒充论文体例等问题；seal 同时绑定所用来源/证据摘要，后续相关变化使验收失效，无关来源增加不要求重审。脚本不证明模型真实读懂或主张正确，比较、述评与学术判断仍须对照原文实际核查，不能自动勾选通过。
