# 公共管理期刊与可读文章入口

本表仅供公共管理及确有关联的辅助学科使用。其他学科按 discipline-routing.md 建立最小来源配置并定向核查原始来源，不以公共管理期刊、FMS 或 CSSCI 作为普遍准入。历史等级/访问记录不代表本轮核验。

维护核验：2026-10-30。只按当前问题选少数入口；不每次重检整个列表。下列是当时的样本访问结果，不保证全刊、下一次访问或其他宿主能读取。读取程度每篇重新据实际登记，不能复制历史核验状态。

FMS 等级据[2025 编制说明](https://fms-journal.net/english?lang=en_us)、[公共管理国际表](https://fms-journal.net/journals/search?lang=en_us&page=0&subject.id=1618&issn=&name=&num=20)、[中文表](https://fms-journal.net/journals_cn)记录。A/T1 是各自列表内部等级，不直接换算；CSSCI 不等于顶刊。等级未知不猜填。专题与跨学科来源按实际用途补充，不统称顶刊。
